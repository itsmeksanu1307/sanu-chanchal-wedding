# Sanu & Chanchal Wedding Invitation

A mobile-first wedding invitation with a new ivory, maroon and gold floral theme, a Lord Ganesha opening, scratch-to-reveal wedding date, countdown timer, chronologically ordered events, RSVP names and a kids' invitation section.

## Publish on GitHub Pages
1. Extract this ZIP.
2. Upload **all files and folders inside** to the root of `itsmeksanu1307/sanu-chanchal-wedding`, replacing the old `index.html`, `style.css`, and `script.js`.
3. Ensure `assets/ganesha-floral-background.png` is uploaded as well.
4. Open **Settings → Pages** and ensure publishing is from `main` / `/(root)`.
5. Wait for deployment, then reload the public website.

Wedding venue is written as **Shubh Nights, Sakri Road, Gangwara, Darbhanga, Bihar 846004**. Event dates are listed in chronological order. RSVP button opens WhatsApp to the existing contact number 7831030267; it does not store RSVP responses in a database.
